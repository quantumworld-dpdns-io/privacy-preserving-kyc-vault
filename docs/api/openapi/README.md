# OpenAPI Specifications

This directory contains the OpenAPI 3.0/3.1 specifications for the KYC Vault services.

- `did-service.yaml`
- `credential-service.yaml`
- `kyc-service.yaml`
- `zkp-service.yaml`
- `billing-service.yaml`
- `webhook-service.yaml`
- `admin-service.yaml`
- `aggregation-service.yaml`
- `gateway.yaml`

Use these specifications to generate client SDKs or explore the API via Swagger UI.
