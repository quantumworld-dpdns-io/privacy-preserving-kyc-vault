# Architecture Diagrams

This directory contains the source files for architectural diagrams.

- `overview.drawio` - High-level system overview
- `services.drawio` - Microservices interaction diagram
- `data-flow.drawio` - Key data flow illustrations
- `deployment.drawio` - Deployment architecture diagrams
- `security.drawio` - Security layers and controls
- `compliance.drawio` - Regulatory compliance mapping

*Note: Use [draw.io](https://app.diagrams.net/) to edit these files.*
